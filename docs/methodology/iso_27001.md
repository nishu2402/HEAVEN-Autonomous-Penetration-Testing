# HEAVEN ↔ ISO/IEC 27001:2022 (Annex A)

Mapping of HEAVEN's detectors against the [ISO/IEC 27001:2022](https://www.iso.org/standard/27001)
Annex A control set (as detailed in ISO/IEC 27002:2022), including
**Amendment 1:2024** (climate-action changes). Annex A groups 93
controls into four themes: **A.5 Organizational**, **A.6 People**,
**A.7 Physical** and **A.8 Technological**.

ISO/IEC 27001 certifies an *Information Security Management System (ISMS)* — a
governance process — so most controls are attested through policy, records and
audit rather than a scan. HEAVEN provides **technical evidence** for the subset
of controls (chiefly under A.8) that have an observable footprint: management of
technical vulnerabilities, secure configuration, network security, cryptography
in transit, and application security testing. People, physical and
policy/governance controls are honestly marked `(organizational)` / `(physical)`
— outside what any external scanner can evidence.

A control row is **✓ exercised** on the live Methodology page only when the
HEAVEN detector it names actually produced a finding in the active engagement.

## Coverage summary

| Annex A theme | HEAVEN evidence |
|---|---|
| A.5 Organizational Controls | mostly organizational; threat-intel & cloud posture partial |
| A.6 People Controls | organizational — HR / training, not scannable |
| A.7 Physical Controls | physical — out of scope for a remote scanner |
| A.8 Technological Controls | extensive — HEAVEN's core evidence surface |

All controls in this theme (screening, terms of employment, awareness training,
disciplinary process, remote working) are **(organizational)** — governed by HR
and the ISMS, with no network-observable footprint.

| Control | Description | HEAVEN coverage |
|---|---|---|
| A.6.3 | Information security awareness, education & training | (organizational — HR / training) |
| A.6.8 | Information security event reporting | (organizational — process control) |
